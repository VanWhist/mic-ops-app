# mic-ops-app

MIC運営（仮）— スタッフ予定・配置の**画面**（GitHub Pages で配信）。

- データはすべて Apps Script（非公開リポジトリ側で管理）から読む。**このリポジトリにはスタッフ名・トークン・スプレッドシートIDを置かない**
- スタッフは自分専用の URL（`…/#t=トークン`）で開く。`#` 以降はサーバーへ送られない
- `config.js` の `apiUrl` が空のときはデモ表示（架空の名前・端末内だけの保存）
  - `#t=demo` … スタッフとして／`#t=demo-admin` … 管理者として／`?fail=1` … 保存失敗の表示を確かめる

| ファイル | 中身 |
|---|---|
| `index.html` / `style.css` / `app.js` | 画面（自分の予定・みんなの予定・役割の希望） |
| `config.js` | 接続先（Apps Script Webアプリの /exec URL） |
| `demo.js` | デモ用の擬似サーバー |

`app.js` の祝日一覧は 2026-11〜2027-03 分（Google カレンダー「日本の祝日」で確認）。シーズンが変わったら足す。

## 端末内キャッシュ（2026-10-03〜）

- 開いたらまず前回の内容を出し、裏で最新を取り直す。上に「○時○分時点」を出す。取れなかったら「前回開いたときの内容です」と出す
- キーは `micops_v1_<トークンのSHA-256の先頭32桁>`。トークンそのものは保存しない
- **保存する形を変えたら app.js の `CACHE_VER` を上げる**
- 本番（config.js の apiUrl あり）では demo.js を読み込まない
